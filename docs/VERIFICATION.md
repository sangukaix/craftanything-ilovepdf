# 검증 기록

## 기존 구현 검증 (2026-11-17)

기존 PC에서 Python PDF/계정/다단 검사 48개 고유 항목과 브라우저 처리 보조 로직 6개 그룹을 검증했습니다. 합성 PDF·DOCX·XLSX·PPTX만 사용했습니다. Office→PDF, PDF/A 실제 veraPDF 검사, HTML Chromium 렌더링, 원문·내장 글꼴·문단·2/3단 260문장 흐름, 로컬 Qwen 요약/번역, 계정별 저장/복호화·시험 결제 중복 안전성을 포함합니다. 물리 카메라, 외부 결제/클라우드/메일/신뢰 기관 인증서는 미검증입니다.

Craft의 약99%는 홈/병합/분할/압축/JPG→PDF의 5화면을 1440/768/390px로 비교한 15개 화면 범위의 반올림 점수입니다. 30/30 화면 주장 검사였습니다. 전체 기능이 99% 동일하다는 인증이 아닙니다. 예전 Craft 화면의93%와 측정 시점·범위가 다릅니다.

## 재현 가능한 검사

- setup.cmd: 상태 검사와 합성 파일 통합 검사. 결과 .local-data/doctor.json 및 .local-data/verification/result.json.
- verify.cmd: 전체 Python 테스트와 Node 클라이언트 검사.
- scripts/audit_pdf_tools.py: 도구/경로 점검.
- AI 미설치 CI/시험: PDF_SKIP_AI_TESTS=1을 명시하면 실제 AI 테스트 2개만 skip. 이를 AI 성공으로 보고하면 안 됨.
- 전체 테스트는 Full 문서 엔진과 실제 AI 서버가 필요합니다. 새로운 모델은 원본 모델과 다른 결과를 낼 수 있습니다.

## Git 배포 준비 검증

2026-11-17, 같은 Windows PC의 별도 빈 소스 폴더에서 Full + Existing 설치를 실행했습니다. 기존 가상환경/node_modules/문서 엔진을 복사하지 않고 공식 배포 도구와 고정 패키지를 새로 다운로드·설치했습니다. AI 서버만 기존 Strata를 재사용했습니다.

- 관리 Python 3.14, 고정 Node, npm ci, 해시 고정 Python 패키지 설치 성공.
- LibreOffice 26.8.3 MSI 추출, Java21, veraPDF1.30.4 무인 설치, Playwright Chromium 새 설치 성공.
- Next.js 정적 빌드 성공, 62개 경로 생성.
- 설치 통합 검사 8/8 통과: 압축/보호/해제, Word/PPT 출력, 2/3단 흐름, 계정/저장/중복 결제, Office3종, PDF/A 검증, HTML, 실제 로컬 AI 요약/번역.
- 전체 Python 52/52 통과(93.871초), Node 클라이언트 6개 그룹 통과.
- 새 빌드 파일을 임시 루프백 HTTP 서버에서 제공해 도구32개·내부 링크87개 검사: 소스 누락0, 실패 링크0.
- AI 제외 모드의 실제 모델 테스트 2개가 명시적으로 skip되는 것도 확인.

같은 PC의 새 폴더 검증이며 다른 하드웨어 시험은 아닙니다. 대형 Strata 모델 전체 재다운로드는 기존 서버를 중단하지 않기 위해 반복하지 않았습니다. 원본 모델 선택 설치 경로는 미검증입니다. Windows CI는 전체 문서 엔진을 설치하되 AI를 명시적으로 제외하고 실행합니다. 최초 CI 실행 상태는 GitHub Actions에서 확인하세요.

## 기본 AI 설치 경로 추가 검증

동일한 새 설치 폴더에 공식 Ollama v0.40.16 포터블 배포를 SHA-256 확인 후 새로 풀고, 프로젝트 전용 포트11435와 모델 저장 폴더를 사용했습니다. qwen3.5:4b를 실제 다운로드하고 문맥32768의 pdf-qwen3.5-4b-32k:latest를 생성했습니다. 모델 목록의 실제 태그와 일치하도록 설치기 설정을 수정했습니다.

Full + Ollama 설치 명령을 다시 실행해 npm ci·웹 빌드·상태 검사와 합성 파일 통합 검사8/8이 통과했습니다. /v1/chat/completions에서 지정한 모델이 실제로 OK를 생성했고, 실제 PDF 요약·한국어 번역도 통과했습니다. 모델을 재사용하는 원래 PC의 대형 모델과 품질·속도가 같다는 뜻은 아닙니다. 이 과정에서 기존 Strata/Ollama 서비스·모델 파일은 변경하거나 중단하지 않았습니다.

Qwen4B로 숫자 보존 요약·한국어 번역 회귀 검사2/2도 추가 통과했습니다. 개인정보 없이 추린 실행 결과는 [install-verification.json](install-verification.json)에 있습니다.


## 미사용 소스 정리 (2026-11-17)

현재 라우트·일반/동적 import를 분석해 참조가 없는 초기 화면 샘플18개, Hello World 시험 파일1개, 미사용 theme.ts를 삭제했습니다. 실제 페이지에서 참조하는 소스79개(스타일/도우미 포함), 문서 처리 코드, 패키지/잠금 파일, 이미지·글꼴·OCR·PDF.js 리소스는 변경하지 않았습니다. 삭제한 소스는10,489바이트입니다.

별도 폴더에서 정리 전후를 같은 시험용 Build ID로 빌드해 비교했습니다(실제 프로젝트의 빌드 설정은 변경하지 않음). 정적 파일608개가 유지되고, 사용하지 않는 Tailwind 스타일823바이트와 그 CSS 파일명 참조 외의 모든 파일은 동일했습니다. JavaScript와 전체63개 HTML 내용이 동일하며, 제거된 유틸리티 스타일은63개 HTML 어느 곳에도 적용되지 않았습니다.

정리 적용 후 Python55/55와 클라이언트7개 그룹이 통과했습니다. 이후 사용자 요청으로 공유 진입 암호를 제거했습니다. 그 변경은 별도로 공유 통합3개와 공개 HTTPS5개 검사로 확인했고, 기존 공개 주소가 유지되며 쿠키 없이 프로젝트 홈이 열리는 것을 실제 브라우저에서도 확인했습니다. 프로젝트 회원 로그인과 보관함 접근 검증은 유지합니다.
