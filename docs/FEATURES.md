# 기능과 제한

| 영역 | 구현 | 범위/제한 |
|---|---|---|
| 파일 입력 | 선택·드래그·다중 목록·제거·정렬 | 도구별 형식·용량 제한 적용 |
| 기본 PDF | 병합·분할·페이지 삭제/정렬·회전·자르기·번호·워터마크 | 암호/손상 문서는 검증 필요 |
| 압축·일괄 | 무손실 최적화, 다중 PDF ZIP | 크기가 줄지 않는 PDF도 있음; 최대 10파일/개별25MB/전체100MB |
| 보호·해제·복구 | 암호화와 올바른 비밀번호로 해제, 복구 시도 | 모든 손상 파일 복구 보장 불가 |
| 이미지·PDF | JPG/PDF, 이미지 내보내기 | 변환 시 원래 편집 구조 보존과 구별 |
| Word·Excel·PPT | PDF→Word/Excel/PPT, Office→PDF | Word는 추출 기반; PPT는 페이지 이미지; Excel은 인식 가능한 표 중심; Office 출력은 LibreOffice 호환성에 따름 |
| OCR | 브라우저 Tesseract 한국어/영어 | 흐림·손글씨·복잡한 표 정확도 제한 |
| PDF/A | PDF/A-2b 변환과 veraPDF 검사 | 검사 통과 여부를 실제 결과로 판단 |
| 원문·문단 편집 | 내장/Base14 글꼴 재사용·자동 대체·줄바꿈·재배치 | 없는 글자는 strict 거부/auto 대체. 임의 PDF의 원래 레이아웃 완전 보존은 아님 |
| 다단 | 명시한 동일 너비 2/3단 흐름·다음 페이지 | 표/도형/링크/양식 등 장애물 보호; 모호한 겹침 거부; 서로 다른 페이지 크기와 신규 페이지 머리말 복제 제한 |
| 양식·검열 | 양식 생성/입력, 텍스트·이미지·관련 주석 영구 제거 | 결과 파일에서 직접 확인 권장 |
| 서명 | 손글씨 이미지 배치, 사용자 인증서 디지털 서명 | 위치/크기 숫자로 조정. 신뢰 기관 인증서·타임스탬프 서비스 별도. 공식 서명 요청 클라우드 서비스 아님 |
| 비교 | 문서 차이 확인 | 모든 의미 차이 자동 판정 아님 |
| 스캔 | 사진 경계 탐지·네 모서리 원근·회전·자르기·명암·다중 페이지, 카메라 입력 | 실제 카메라 장치 시험 별도; 브라우저 권한 필요 |
| HTML | HTML/공개 URL→PDF, 선택적 JS | 사설망/file URL 차단; 외부 웹사이트 호환성 제약 |
| AI | 로컬 모델 요약·번역 | 별도 모델 필요, 긴 문서 한도·환각·번역 레이아웃 손실 가능 |
| 작업 흐름 | 여러 PDF 처리 단계 연결 | 보호/PDF-A 등 종료 단계 제약 |
| 계정·저장 | 로컬 회원/세션, 암호화 파일 보관 | 외부 클라우드·SSO·이메일 검증/복구·기기 동기화 미연결 |
| 결제 | 성공/실패/취소·중복 처리 시험; Toss 시험 어댑터 | 실제 결제/외부 위젯·웹훅은 키 없이 미검증·미연결 |

홈 화면과 도구 화면이 존재한다는 사실은 모든 문서·모든 원본 서비스 동작을 지원한다는 뜻이 아닙니다. 퍼센트 점수 대신 위 기능과 실제 시험 결과를 확인하세요.
