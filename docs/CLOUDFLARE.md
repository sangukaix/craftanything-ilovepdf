# 선생님께 Cloudflare 링크로 공유하기

## 시작·접속·종료

1. 새 PC에서는 먼저 setup.cmd로 설치·빌드합니다.
2. 프로젝트의 start-cloudflare-share.cmd를 더블클릭합니다. 처음에는 공식 cloudflared 실행 파일을 SHA-256 검증 후 프로젝트 안에 내려받습니다.
3. 표시된 HTTPS 주소를 선생님께 전달합니다. 공유 암호나 별도 로그인 없이 프로젝트 첫 화면이 바로 열립니다. 선생님은 브라우저만 있으면 됩니다. Tailscale·Ollama·Python 설치가 필요하지 않습니다.
4. 같은 실행기를 다시 열면 실행 중인 주소를 다시 보여 줍니다. 로컬 .local-data/share/access.txt에도 있습니다. 이 파일이나 session.json을 Git에 올리지 마세요.
5. 종료하려면 stop-cloudflare-share.cmd를 실행합니다. 이 프로젝트의 공유 프로세스만 중단하며 기존 PDF·AI 서버는 종료하지 않습니다.

PC를 켜고 인터넷을 연결한 동안 사용할 수 있습니다. 브라우저나 실행 안내 창은 닫아도 백그라운드 공유는 유지됩니다. PC를 종료하거나 절전 모드로 들어가면 사용할 수 없습니다. 다시 시작하면 새 주소가 생성되므로 다시 전달해야 합니다. Quick Tunnel은 임시 시연용이며 가동률을 보장하지 않습니다.

고정 주소와 상시 운영에는 Cloudflare 계정으로 만든 정식 Tunnel과 계정/도메인 구성이 별도로 필요합니다. PC가 꺼져도 계속 사용하려면 앱 처리 서버를 별도 컴퓨터/서버로 옮겨야 합니다. 현재 구성은 Cloudflare에 앱 실행 환경을 호스팅한 것이 아닙니다.

## 처리·접근 범위

- 웹 화면은 이 프로젝트의 app/out만 제공합니다. 저장소 루트·개인 폴더·설정 파일은 공개하지 않습니다. 디렉터리 목록을 제공하지 않습니다.
- 프로젝트 화면과 일반 PDF 도구는 공개입니다. 링크를 가진 방문자는 공유 암호 없이 접근합니다. 개인 보관함은 프로젝트 내 회원 로그인과 CSRF 검증이 그대로 필요합니다.
- 병합 등 일부 기능은 방문자의 브라우저에서 처리합니다. Word·Office·PDF/A·편집·요약 등 서버 기능은 HTTPS/Cloudflare를 통해 운영자 PC로 파일을 전송합니다. 기밀/개인 문서를 시험 자료로 쓰지 마세요.
- 공개 주소에서 PDF·계정 API를 같은 HTTPS 주소로 호출합니다. 방문자 PC의127.0.0.1에 접속하지 않습니다. 사설 API는 계속 루프백에만 바인딩합니다. 방화벽·공유기 인바운드 포트를 열지 않습니다.
- 기존 개인 계정·보관함을 연결하지 않습니다. 공유 전용 .local-data/share/accounts에 별도 회원·파일을 저장합니다. 계정 저장소는 암호화하지만 운영자 PC에서 관리되는 시험용 보관함입니다. 실제 클라우드 저장소/결제는 제공하지 않습니다.
- 공유 계정에서는 모의 결제만 노출하고 외부 결제 승인·웹훅 경로는 공개하지 않습니다.
- 처리 요청은 동시에2개로 제한됩니다. 큰 문서·느린 AI 요청은 터널 시간 제한에 걸릴 수 있으므로 시연에는 작은 합성 파일을 권장합니다.

일반 PDF 도구는 로그인 없이 사용할 수 있습니다. 공유 전용 계정의 비밀번호·세션 데이터와 운영자의 개인 데이터는 GitHub에 올리지 마세요. 공유를 완전히 해제하려면 종료 실행기를 쓰세요. PC 자동 시작, Windows 서비스 등록, Cloudflare 계정 로그인은 구성하지 않았습니다.

업데이트 후 같은 임시 주소를 유지하려면 실행 중인 프로젝트에서 `.pdf-service-venv\Scripts\python.exe scripts\share_cloudflare.py reload`를 사용합니다. 검증된 이 프로젝트의 웹 프로세스만 교체하고 기존 Cloudflare 터널을 재사용합니다.

## 검증 기록 (2026-11-17)

- 새 공유 게이트웨이 통합 테스트3개: 암호 없는 직접 접속과 호스트/출처/비공개 경로 차단, 실제 PDF 처리·별도 계정 왕복, 보관함 로그인 요구·미지원 경로 차단 통과.
- 공개 Cloudflare HTTPS 경로5검사: 쿠키 없는 프로젝트 직접 접속, 비공개 경로/출처 거부, 실제 PDF 압축, 실제 로컬 AI 요약(숫자180 보존), 보관함 업로드·다운로드/CSRF 통과.
- 실제 브라우저에서 합성 PDF를 선택해 Word를 다운로드하고 결과 글자를 확인했습니다. 두 PDF를 병합해3쪽 PDF를 다운로드하고 내용·페이지 수를 확인했습니다.
- 다른 물리 PC/휴대폰이나 별도 통신망에서 사람이 접속하는 시험은 아직 하지 않았습니다. 같은 PC에서 공개 Cloudflare 엣지를 거쳐 검증했습니다.

재검사: 실행 중인 공유에서 .pdf-service-venv\Scripts\python.exe scripts\verify_share.py. 합성 시험 계정·파일만 생성하며 결과는 .local-data/share/public-verification.json에 남습니다. 이 로그에는 계정 비밀번호를 기록하지 않습니다.

공식 설명: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/
